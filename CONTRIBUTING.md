# Contributing

Thanks for helping improve this repository.

1. Fork the repository and branch from `main`.
2. Keep one change per pull request.
3. Say in the pull request what you ran to check the change.
4. Never include keys, tokens or other secrets in a commit, issue or pull request. Use `.env.example` for placeholders.

Report security problems privately, as `SECURITY.md` describes.

See `LICENSE` for the terms. By contributing you agree your contribution may be distributed under those terms.
