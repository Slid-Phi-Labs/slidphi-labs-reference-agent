# Security policy

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue or pull request about one.

Use the "Report a vulnerability" button on this repository's Security tab (GitHub private vulnerability reporting).

Include the commit you tested, the steps or input that trigger the problem, what you expected, what happened, and the impact in plain words. Report one issue per report.

## Testing rules

- Test on your own machine with your own files and placeholder keys.
- Do not access, copy or keep data that is not yours.
- Keep details private until a fix is released.
